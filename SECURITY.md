# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately from this repository's **Security** tab using
"Report a vulnerability" (GitHub private vulnerability reporting).

Include the affected package and version, steps to reproduce and the impact you expect. We aim to acknowledge
reports within 5 business days and to agree on a disclosure timeline with you.

## Supported versions

Until 1.0, only the latest 0.x release receives security fixes.

## How fixes are handled

Fixes are prepared privately, released, and then disclosed in a GitHub security advisory that credits the
reporter (unless you prefer otherwise).
