# Roadmap

This roadmap is public and shaped by the community. Propose changes with an RFC (see [GOVERNANCE](GOVERNANCE.md)).

## Now (0.x)

- `request-validation` and `api-docs`: stabilize APIs, improve docs and examples.
- Publish to npm with provenance once the APIs settle.

## Next

- Lead capture: a provider-neutral contract and helpers for contact and inquiry forms, with configurable categories.
- Media storage: a provider-neutral media ingestion contract with local storage.
- UI building blocks: form components and theme tokens.

## Later

- Examples: a minimal NestJS service using every package.
- Additional storage and validation adapters proposed by the community.
